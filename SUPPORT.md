# Getting help

Thanks for using Yeliztli! Here's where to go, depending on what you need.

## 📖 Start with the docs

The documentation site answers most questions:

**<https://bioedca.github.io/Yeliztli/>**

- [Getting started](https://bioedca.github.io/Yeliztli/getting-started/) — install, upload your DNA, read your results
- [Install & self-host](https://bioedca.github.io/Yeliztli/install/) — native, Docker, WSL2, configuration, troubleshooting
- [Module reference](https://bioedca.github.io/Yeliztli/modules/) — what each analysis module reports and how to read it

## 💬 Ask a question

For usage and how-to questions, use **[GitHub Discussions → Q&A](https://github.com/bioedca/Yeliztli/discussions/categories/q-a)**.
This keeps the issue tracker focused on actionable bugs and features, and lets
other users find answers later.

Have an idea or want to float a direction that isn't a concrete proposal yet?
Use **[Discussions → Ideas](https://github.com/bioedca/Yeliztli/discussions/categories/ideas)**.

## 🐞 Report a bug or request a feature

If something is broken or missing, open an issue with the matching template:
**[New issue](https://github.com/bioedca/Yeliztli/issues/new/choose)**. Pick the
Bug report, Feature request, Scientific validity, Documentation, or Design
proposal form. One issue per problem, please.

## 🔒 Security

Do **not** report vulnerabilities in public. See **[SECURITY.md](SECURITY.md)**
for private reporting.

## ⚠️ A reminder on your data

Yeliztli is privacy-first and runs entirely on your machine. **Never paste your
raw genotype data, attach your genome file, or share rsID + genotype lines** in
any public issue or discussion. Use a small synthetic/test input to demonstrate
a problem.

## ⚕️ Not medical advice

Yeliztli is for research and educational use only — results are not diagnostic
and not clinically validated. See
[Intended use & disclaimers](https://bioedca.github.io/Yeliztli/intended-use/).
