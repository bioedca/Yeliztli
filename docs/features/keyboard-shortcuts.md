# Keyboard shortcuts

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + K` | Open the command palette |
| `Escape` | Close a panel or dialog |

## Sample selector

Focus the sample selector in the top navigation and press `Enter` or `Arrow Down` to
open it. Use `Arrow Up` and `Arrow Down` to move between visible rows, `Arrow Right`
to expand an individual or enter its samples, and `Arrow Left` to collapse it or
return to its parent. `Home` and `End` move to the first and last visible rows.

Press `Enter` on a sample to select it. Selection and `Escape` close the tree and
return focus to the selector button. `Tab` moves to the next page control and
closes the tree. `Shift + Tab` first returns to the selector button; pressing it
again leaves the selector and closes the tree, keeping focus on the previous control.

## Command palette

Press `Cmd + K` (macOS) or `Ctrl + K` (Linux/Windows) to open the command palette and quickly
search for:

- **Variants** by rsID or gene name,
- **Pages** by name (Dashboard, Settings, any module),
- **Actions** such as switching samples or toggling dark mode.

The command palette is **navigation-only** — it performs no destructive or state-changing
actions.
