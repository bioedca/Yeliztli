License

dbNSFP is distributed in two branches — the academic branch and the commercial branch — licensed separately for non-commercial and commercial use.

Non-Commercial Use

The dbNSFP academic branch is distributed free of charge for academic and non-commercial use under CC BY-NC-ND 4.0, and includes all upstream resources that are free for academic and non-commercial use.

Users of the academic branch are responsible for complying with the individual licensing requirements of its components, which are listed in the README file of the current release. Obtaining the academic branch data from any source does not grant commercial use rights for these scores or content.

Commercial Use

The dbNSFP commercial branch is licensed for commercial use with a fee, including downloading the full data for local workflow integration and product development. Genos Bioinformatics LLC is the exclusive provider of these licenses, and currently offers two standard tiers:

  • Internal Research Use — $5,000/year
  • Product Development and Internal Research Use — $10,000/year

The dbNSFP commercial branch is based on the academic branch, but excludes upstream components that require a separate license for commercial use from their authors (see the FAQ).

FAQ

How often will dbNSFP make a new release?

We release a new version of dbNSFP 3–5 times a year, incorporating updated data from the field, new content from academic collaborators, and rebuilt nsSNV and ssSNV variant sets based on the latest GENCODE releases. Please see the Releases page for information on current and past versions.

What does the dbNSFP commercial branch include?

The dbNSFP commercial branch includes all academic branch content, except for CADD, VEST, M-CAP, MutScore, PolyPhen-2, PrimateAI, and RGC Million Exome. dbNSFP commercial licensees who need these components should contact their authors directly (contacts listed in README v5.4c). We can also make a customized dbNSFP version for you by adding back the approved components, given appropriate proof of your commercial use rights for those scores.

The prediction scores included in the current release are:

  • SIFT, SIFT4G, PROVEAN, MutationTaster 2021, MutationAssessor, FATHMM-XF coding, DANN, MetaSVM, MetaLR, MetaRNN, Eigen, Eigen-PC, REVEL, MutPred2, MVP, gMVP, MPC, DEOGEN2, ALoFT, BayesDel, ClinPred, LIST-S2, VARITY, ESM1b, AlphaMissense, PHACTboost, MutFormer, MisFit, popEVE, and GPN-MSA.

For an independent evaluation of prediction score performance, see the CAGI6 report (Rastogi et al., Human Genetics, 2025). We also performed our own benchmark study based on nine years of ClinVar data, with the method described in our blog post. We encourage users to consult these results when evaluating which scores best suit their own applications.

Is a commercial license required for legacy versions of the dbNSFP commercial branch?

The dbNSFP team has been distributing the commercial branch since dbNSFP v3.0 (released in 2015). As a courtesy, a commercial license is not required for legacy versions, meaning dbNSFP v4.x and earlier. We encourage commercial users to use the most current annotation resources in the latest dbNSFP commercial branch release.

What are the differences between the current dbNSFP release and the legacy versions?

Biological data and genome annotations change rapidly. Beyond the many updated annotation resources and new prediction scores added in each release, the dbNSFP v5.x variant set was rebuilt based on current gene definitions from GENCODE. The latest legacy versions, dbNSFP v4.x, were built on GENCODE v29 (released October 2018). The current GENCODE release (v50, released June 2026) not only adds 235% more protein-coding transcripts — 83,129 in v29 compared with 278,455 in v50 — but also updates the canonical/MANE transcript for some genes.
