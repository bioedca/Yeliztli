Current Release

dbNSFP v5.4 (August 1, 2026)

README v5.4a Variant Columns v5.4a README v5.4c Variant Columns v5.4c Gene Columns v5.4

  • Fully rebuilt variant set based on GENCODE release 50 (Ensembl release 116, June 2026).
  • Added GPN-MSA scores to both the academic and commercial branches.
  • Removed PrimateAI in the commercial branch. It remains in the academic branch.
  • Updated ClinVar, GWAS Catalog, InterPro, ALFA, and MANE.
  • Updated gene annotation resources including ClinGen, GenCC, Gene Ontology, HGNC, HPO, IntAct, MGI, OMIM, Orphanet, UniProt, Ensembl, RefSeq, and ZFIN.

Past Releases

dbNSFP v5.3.1 (January 1, 2026)

README v5.3.1a README v5.3.1c

  • Added popEVE scores, derived from a deep generative model combining evolutionary and human population data to estimate variant deleteriousness on a proteome-wide scale.
  • Added hs1 (T2T-CHM13 v2.0) reference genome coordinates.
  • Added support for hs1 (T2T-CHM13 v2.0) coordinate search in the search_dbNSFP annotation program and dbNSFP web service.

dbNSFP v5.3 (October 6, 2025)

README v5.3a README v5.3c Change Log

  • Rebuilt variant set based on GENCODE release 49 (Ensembl release 115, September 2025), significantly expanding human protein-coding transcripts using long-read sequencing data.
  • Added MisFit scores v1.5.1, a novel method to estimate missense fitness effects using a graphical model.
  • Added GERP_92_mammals conservation score to replace GERP_91_mammals score.
  • Added gene constraint measures from gnomAD v4.1: gnomAD_lof.oe, gnomAD_LOEUF, gnomAD_mis.oe, and gnomAD_MOEUF.
  • Updated ClinVar, GWAS Catalog, InterPro, ClinGen, GenCC, Gene Ontology, HGNC, HPO, IntAct, MGI, OMIM, Orphanet, UniProt, Ensembl, RefSeq, and ZFIN.

dbNSFP v5.2 (July 2, 2025)

README v5.2a README v5.2c Change Log

  • Rebuilt variant set for all possible nsSNVs and ssSNVs based on GENCODE release 48 (Ensembl v114).
  • Added MutPred2 to replace MutPred v1.2 scores, included in both academic and commercial branches.
  • Updated ESM1b scores to include more missense mutations.
  • Added GenCC gene annotations.

dbNSFP v5.1.1c (April 24, 2025)

README v5.1.1c

  • Added ClinPred, REVEL, and PHACTboost to the dbNSFP commercial branch.

dbNSFP v5.1 (March 21, 2025)

Highlights README v5.1a README v5.1c Change Log

  • Rebuilt variant set based on GENCODE release 47 (Ensembl v113).
  • Added allele frequencies from All of Us and Regeneron Genetics Center Million Exome.
  • Added dbNSFP_POPMAX_AF/AC based on all population allele frequency columns curated in dbNSFP.
  • Provided dbNSFP files in formats ready for use with Ensembl Variant Effect Predictor and SnpSift.

dbNSFP v5.0 (January 1, 2025)

README v5.0a README v5.0c

  • Fully rebuilt based on GENCODE release 46 / Ensembl release 112.
  • Added MANE transcript annotations.
  • Updated TOPMed, gnomAD, bStatistic, ancestral alleles, ClinVar, and MutationTaster2021.
  • Retired legacy resources including LRT, FATHMM, fathmm-MKL, fitCons, LINSIGHT, GenoCanyon, EVE, SiPhy scores, ESP, ExAC, UK10K, GTEx, eQTLGen and Geuvadis eQTLs.
